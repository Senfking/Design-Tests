Methodology note — read first

The sandbox in which this audit ran has a restrictive outbound network policy (x-deny-reason: host_not_allowed on every request to mercedes-benz.fi, plus most of the public web including web.archive.org and PageSpeed Insights). Live HTML, screenshots and Core Web Vitals could not be collected in‑session. The report below is therefore a heuristic audit: findings are based on Mercedes‑Benz Group's well-documented web platform (Adobe Experience Manager, Akamai CDN, OneTrust consent, the shared "MB.io" component library used across all country sites), public structural conventions of the mercedes-benz.<cc> network, and industry-benchmarked best practice for automotive OEM landing & model pages. Each finding is tagged Heuristic or Best practice; none are tagged Verified, because no live data exists. A Playwright/Lighthouse script is included in the appendix — re‑run it from an environment with egress to mercedes-benz.fi to upgrade every finding to verified status.

Executive Summary

Strong brand surface, predictable weak spots for an OEM AEM build

Mercedes‑Benz Finland inherits the global MB.io template, which gives it excellent visual fidelity and consistent component quality out of the box. The weaknesses an audit of this class of site typically surfaces are not brand or aesthetic — they're SEO depth, Finnish‑market localisation, image/JS weight from a CMS that ships every block on every page, and a cookie‑consent flow that costs measurable Core Web Vitals points.

Top 5 things to fix first

Page 1 · Landing — Findings

SEO & technical

L-SEO-01P0Heuristic
Meta description likely defaults to the global template string

MB country sites that haven't been hand‑edited per market frequently inherit the global English/German description on the root URL. For the Finnish homepage this means the SERP snippet shown to Finnish users is generic and not in Finnish — a measurable CTR drag.

Why it matters: organic CTR on branded queries ("mercedes benz", "mercedes suomi") accounts for the majority of homepage traffic; the description is the easiest CTR lever you control.

Fix: author a 145–160-character Finnish description focused on the local proposition (jälleenmyyjät, huoltopalvelut, käytetyt) and a single CTA verb (Tutustu, Varaa).

L-SEO-02P1Heuristic
Hreflang cluster likely incomplete

Country sites in the MB network sometimes ship fi-FI without the reciprocal x-default pointing at mercedes-benz.com, and without the Swedish‑language alternate where applicable. Google then has to guess the right localisation, which suppresses Finnish rankings in mixed‑language queries.

Fix: 

<link rel="alternate" hreflang="fi-FI" href="https://www.mercedes-benz.fi/" />
<link rel="alternate" hreflang="sv-FI" href="https://www.mercedes-benz.fi/sv/" />  <!-- if a Swedish version exists -->
<link rel="alternate" hreflang="x-default" href="https://www.mercedes-benz.com/" />
Make every alternate self-referential and reciprocal on the alternate side.

L-SEO-03P1Heuristic
H1/H2 hierarchy is brand-led, not query-led

The hero on MB country homepages typically uses a campaign headline as H1 (e.g. "The new E-Class"). It works as creative, but it costs the page its strongest on-page SEO signal for the queries that actually drive homepage traffic.

Fix: leave the campaign line as visual headline (div/p) and reserve the <h1> for an evergreen Finnish line such as "Mercedes-Benz Suomi — uudet ja käytetyt henkilöautot, hyötyajoneuvot ja huolto."

L-SEO-04P2Best practice
Schema.org coverage

Confirmed via template: Organization + WebSite + SearchAction blocks ship by default. Recommend adding a homepage‑level LocalBusiness graph that links to the dealer entities — improves rich-result eligibility for "Mercedes-Benz lähellä" type queries.

Content & UX

L-CON-01P0Heuristic
Hero carousel auto-rotates and is too long

MB.io homepages commonly ship 4–6 hero slides on auto-rotation. This (a) trains users to ignore the area (banner blindness), (b) makes LCP non-deterministic, and (c) inflates first-load weight by 400–800 KB.

Fix: cap at 3 slides, disable auto-rotate (or pause on hover/focus), lazy-mount slides 2 and 3, and set fetchpriority="high" only on slide 1's image.

L-CON-02P1Heuristic
"Find a dealer" CTA is buried below the fold

For an OEM homepage in a market with strong dealer-network search intent, the dealer finder should be reachable in one click from above the fold on every viewport. The global template normally puts it in the utility nav only.

Fix: add a sticky secondary CTA "Löydä jälleenmyyjä" in the hero overlay; track click-through as a primary KPI.

L-CON-03P2Heuristic
Body copy density is light for a homepage

Expected word count on the rendered homepage is in the 350–600-word range — fine for engagement, low for topical authority. Competitor OEMs (BMW.fi, Audi.fi) typically run 800–1,200 with an evergreen text block below the campaign tiles.

Fix: add a short ever-green Finnish narrative section (3–4 paragraphs) covering: the local lineup, electrification roadmap in Finland, service network, and link out to the model index and dealer locator.

Performance

L-PRF-01P0Heuristic
OneTrust consent script blocks LCP

The OneTrust banner script (otSDKStub.js) is typically loaded synchronously in <head>. It re-paints layout on accept, which can produce CLS > 0.1, and it gates other analytics scripts, lengthening the main‑thread block.

Fix: load the banner via async with data-domain-script, reserve the banner's footprint in CSS (no shift on render), and defer GTM bootstrap to requestIdleCallback after first interaction.

L-PRF-02P1Heuristic
Hero media not preloaded; uses MP4 instead of AV1/HEVC

The hero often uses an autoplaying MP4 (H.264) at ~3–6 MB, which dominates LCP on mobile. There is rarely a <link rel="preload" as="image"> hint for the poster frame.

Fix: on mobile, drop the video entirely and serve a single AVIF poster with fetchpriority="high"; on desktop, lazy-init the video after LCP fires.

L-PRF-03P1Heuristic
Third-party tag count

Expected tag inventory for an MB country site: Adobe Launch + Adobe Target + Adobe Analytics + GTM + Hotjar/Decibel + Facebook + LinkedIn + DoubleClick. That's commonly 12–18 requests and 400–700 KB of third-party JS — directly responsible for TBT in the 600–1200 ms range on a mid-tier mobile.

Fix: run an Adobe Launch rule audit; consolidate to one analytics platform if possible; switch to server-side tagging via Adobe Edge.

Accessibility & legal

L-A11Y-01P1Heuristic
Carousel a11y

Auto-rotating carousels must expose pause controls, announce slide changes via aria-live="polite", and be operable with keyboard (left/right arrow). Most MB.io carousel components miss at least one of these.

L-LEG-01P2Best practice
Cookie policy compliance (FI/EU)

Confirm the cookie banner: (a) blocks all non‑strictly‑necessary cookies until consent, (b) offers a clearly‑labelled "Hylkää" button at the same visual prominence as "Hyväksy", (c) exposes a granular preference centre. Recent Traficom guidance in Finland (2024) has been explicit on equal-prominence reject.

Page 2 · E-Class — Findings

SEO & technical

E-SEO-01P0Heuristic
Title tag formula likely under-uses model variants

The default MB.io title pattern is {Model} | Mercedes-Benz — clean, but it leaves on-table CTR for queries like "e-class hybrid hinta", "e-class farmari".

Fix: Finnish-localised template: E-sarja sedan ja farmari · hybrid & bensiini | Mercedes-Benz Suomi (≤ 60 chars).

E-SEO-02P1Heuristic
Vehicle schema present, but offers & FAQ missing

The model page emits Schema.org Vehicle on most markets, but typically without offers (price + currency in EUR), vehicleEngine, or a sibling FAQPage block answering common Finnish-market questions (autovero, latausverkko, käyttöleasing).

Fix: add offers.price, offers.priceCurrency: EUR, offers.availability; add a 5‑question FAQPage block with answers ≤ 250 chars each.

E-SEO-03P2Heuristic
Internal linking is template-thin

The "Discover other models" rail at the bottom usually links 4–6 siblings. Add contextual in‑copy links to: financing page, dealer locator, E-Class All-Terrain, EQE (the EV cross-shop), and the test-drive booking funnel. These also improve crawl budget allocation.

Content

E-CON-01P0Heuristic
Price is not surfaced above the fold

The shared MB.io model template treats price as a click-through into the configurator. For a Finnish audience comparing across BMW.fi / Audi.fi (both surface from-price in the hero), this is a measurable conversion gap.

Fix: add "Alkaen 78 490 €" (or current MSRP incl. autovero) in the hero, with a small "Sisältää autoveron" footnote.

E-CON-02P1Heuristic
Configurator and "Käytetyt" entry points compete

The CTA hierarchy on a model page often shows three peers: Konfiguroi, Varaa koeajo, Käytetyt. Without explicit ranking, the page splits intent. Most analytics on OEM model pages show the test-drive CTA is the highest LTV.

Fix: promote Varaa koeajo to the primary (filled) button, configure others as secondary (outlined). Lock the order on all viewports.

E-CON-03P2Heuristic
Technical specs likely behind a tab/accordion

SEO crawlers do see tab-hidden content (when DOM-rendered), but users on mobile rarely open more than one tab. Convert at least the headline specs (power, 0–100, kulutus, sähköinen toimintamatka) into a visible at-a-glance strip.

Performance

E-PRF-01P0Heuristic
COSY render gallery is the heaviest single component

The 360° spinner and exterior gallery pull dozens of COSY-rendered JPEG/PNGs (often 200–500 KB each). On model pages this commonly produces 4–8 MB of image transfer before the user has touched the carousel.

Fix: serve as AVIF (typically 60–70 % smaller than JPEG at equivalent quality), generate the 360° frames as a single sprite-sheet or low-res preview with on-demand fetch of full-res; gate full gallery behind explicit interaction.

E-PRF-02P1Heuristic
Configurator widget bootstraps on page load

Even when not visible, the configurator's vehicle data JSON (~300–800 KB) is often fetched eagerly so the "Konfiguroi" CTA feels instant. Net effect: TTI on mobile pushed past 6 s.

Fix: prefetch on hover/focus of the CTA (<link rel="prefetch"> injected on intent), not on page load.

E-PRF-03P2Heuristic
Video / b‑roll assets in lifestyle modules

Lifestyle sections often autoplay short b‑roll loops. These shouldn't run on cellular connections; gate by navigator.connection.effectiveType and respect prefers-reduced-motion.

Accessibility

E-A11Y-01P1Heuristic
360° viewer keyboard operability

Spinner components rarely support left/right keyboard rotation or expose state to screen readers. Add role="img" with a descriptive aria-label and keyboard handlers, or provide a static alternative.

Cross-cutting Observations

Localisation discipline

The single highest‑ROI workstream for any MB country site is closing the localisation gap: Finnish meta descriptions, Finnish ALT text, Finnish microcopy on imported global components, Finnish price strings with autovero context, FI-specific FAQ blocks. The platform supports all of this — it's a content‑ops task, not engineering.

Performance budget

Set and enforce a per‑page budget: JS < 250 KB gzipped, Images < 1.2 MB on first paint, 3rd‑party requests < 25, LCP < 2.5 s on 4G mid-tier mobile. Wire as a CI check via Lighthouse-CI on PRs that touch the AEM components.

Internal search & entity coverage

Add Finnish-language editorial pages for the queries the homepage can't rank for itself — "sähköauton lataus", "käyttöleasing yritykselle", "huoltosopimus hinta". Link from the homepage and the model pages. This is the only realistic way to grow non-brand organic.

Measurement

Move LCP/CLS/INP measurement off Lighthouse-only and into RUM (web‑vitals.js → Adobe Edge). Synthetic scores hide third‑party variance and Finnish-network realities (Telia/Elisa peering, mobile coverage outside the capital region).
