# Project Rules

## Before reporting any task complete
1. Visually verify the change in the Live Preview at http://127.0.0.1:3000/index.html
2. Confirm every image slot displays an actual render — no empty boxes, no broken icons, no zero-byte files.
3. Test responsiveness at three widths: 1920px (desktop), 1280px (laptop), 768px (mobile). Layout must not break at any of these.
4. Check the browser console for errors.

## Quality bar
- This is a Mercedes-Benz dealer pitch artifact. Visual fidelity is the only metric that matters.
- Aesthetic: refined-minimal premium. Dark mode only. Single accent `#5b9dd9`.
- No placeholders, no Wikipedia user photos, no parking-lot snapshots. Only clean MB COSY-style renders or premium press imagery.
- If something breaks during a change, fix it before claiming done.

## Communication
- If a requirement is ambiguous, ask before guessing.
- If a download fails or a path is wrong, flag explicitly and propose alternatives.
- Don't add new sections without asking — the page structure is set.
